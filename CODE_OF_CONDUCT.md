# Code of Conduct

## Our standard

Everyone participating in this project — in issues, pull requests, discussions, and reviews — is expected to:

- Be respectful and professional; critique code and ideas, never people.
- Assume good faith, especially across language and experience differences.
- Keep review feedback specific, technical, and actionable.
- Accept maintainer decisions on scope; this crate is intentionally small.

Unacceptable behavior includes harassment, personal attacks, discriminatory language, sustained disruption, and publishing others' private information.

## Enforcement

Report conduct concerns privately to the maintainer via GitHub (@frankxue831). Reports are handled confidentially. Maintainers may edit or remove contributions and may warn, temporarily restrict, or ban participants whose behavior violates this code.

## Attribution

This is a lightweight policy written for this project. Projects looking for a more detailed standard may prefer the [Contributor Covenant](https://www.contributor-covenant.org/), which this policy is compatible with in spirit.
