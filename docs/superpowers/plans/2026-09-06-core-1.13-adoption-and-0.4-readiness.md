# Core 1.13 Adoption and 0.4.0 Readiness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Adopt the released gmcrypto-core 1.13.0 in both dependency resolutions, review the cryptographic boundary, and prepare a validated 0.4.0 release candidate.

**Architecture:** Keep the existing synchronous, whole-message envelope API and wire profiles. Refresh the dependency and its evidence together, then validate an immutable candidate with the existing repository gates. Treat new envelope features as a separate design decision after this work.

**Tech Stack:** Rust 1.85+, Cargo, existing shell gates, cargo-deny, cargo-public-api, cargo-fuzz, GitHub Actions.

**Spec:** Existing behavioral constraints come from `docs/superpowers/specs/2026-08-20-0.4.0-identity-and-sm4-ccm-design.md` and `SECURITY_MODEL.md`; dependency review requirements from `docs/security/cryptographic-dependencies.md`; release states from `RELEASE_CHECKLIST.md`. Owner approved implementation on 2026-09-06. The approved endpoint is a local `rc-built` artifact set; release approval, publication sequencing, and new feature design are outside this work.

## Global constraints

- Crate identity remains `0.4.0`; `rust-version = "1.85"`; `default = []`; `aead = ["gmcrypto-core/sm4-aead"]`.
- Preserve `gmcrypto-core = { version = "1.11", features = ["x509"] }` in the root manifest. Do not adopt new upstream APIs in this update.
- Preserve existing wire bytes, mandatory SM2 signatures, mode pinning, error categories, and public API snapshots.
- Keep GCM recommended for new integrations. CCM retains the 12-byte nonce, 16-byte tag, 64 KiB default plaintext limit, and `2^24 - 1` ceiling.
- Current document versions: security model 3, engineering evidence 3, inventory 2, API policy 2, checklist 2. A new registry checksum is not by itself a schema-version change.
- Historical tags remain immutable. A dependency change requires a new RC artifact identity.
