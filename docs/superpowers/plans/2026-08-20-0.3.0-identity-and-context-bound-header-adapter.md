# 0.3.0 Identity and ContextBound HeaderProtocolAdapter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Open 0.3.0 identity on `main`, then add exclusive ContextBound support to `HeaderProtocolAdapter` per `docs/superpowers/specs/2026-08-20-0.3.0-identity-and-context-bound-header-adapter-design.md`.

**Architecture:** Train A is a version-identity commit with no adapter behavior change. Train B keeps one `HeaderProtocolAdapter` and stores `Legacy` vs `ContextBound` on `HeaderSchema`. Context bytes are crate-owned: version `0x01`, direction `0x01`/`0x02`, then `u64` big-endian length-prefixed UTF-8 fields. `ProtocolAdapter` is unchanged. Mode/context mismatch stays envelope behavior (`AuthenticationContext` outbound, `InvalidEnvelope` inbound).

**Tech Stack:** Rust 2024 (MSRV 1.85), existing `gmcrypto-core` 1.11, POSIX sh release-identity tests, pinned `cargo-public-api` on `nightly-2026-05-23`.

## Global Constraints

- Do not retarget, move, or delete annotated tag `v0.2.0` (`c7075b75d7460327d741814a15ff28fa1c1ec478`). Do not `cargo publish`. Do not store `CARGO_REGISTRY_TOKEN` in GitHub Actions.

```rust
const HEADER_CONTEXT_VERSION: u8 = 0x01;
const HEADER_CONTEXT_REQUEST: u8 = 0x01;

fn require_exact_trim(value: &str) -> AdapterResult<&str> {
    if value.trim().is_empty() || value != value.trim() {
        return Err(adapter_error(AdapterErrorKind::InvalidField));
    }
    Ok(value)
}

fn push_length_prefixed(buffer: &mut Vec<u8>, value: &str) -> AdapterResult<()> {
    let length = u64::try_from(value.len()).map_err(|_| adapter_error(AdapterErrorKind::InvalidField))?;
    buffer.extend_from_slice(&length.to_be_bytes());
    buffer.extend_from_slice(value.as_bytes());
    Ok(())
}

fn bound_context(bytes: Vec<u8>) -> AdapterResult<AuthenticationContext> {
    AuthenticationContext::context_bound(bytes)
        .map_err(|_| adapter_error(AdapterErrorKind::InvalidField))
}

fn encode_request_context(operation: &str, request_id: &str) -> AdapterResult<AuthenticationContext> {
    let operation = require_exact_trim(operation)?;
    let request_id = require_exact_trim(request_id)?;
    let mut bytes = Vec::new();
    bytes.push(HEADER_CONTEXT_VERSION);
    bytes.push(HEADER_CONTEXT_REQUEST);
    push_length_prefixed(&mut bytes, operation)?;
    push_length_prefixed(&mut bytes, request_id)?;
    bound_context(bytes)
}
```
